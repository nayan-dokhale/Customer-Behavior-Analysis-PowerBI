# 🛒 Customer Behavior Analysis (Power BI, SQL & Python)

An end-to-end data analytics project exploring customer purchasing patterns, demographical spending, product category performance, and subscription dynamics using **Python**, **SQL**, and **Power BI**.

---

## 📁 Repository Structure

```text
.
├── Customer Behaviour Analysis.ipynb       # Python notebook for EDA, cleaning & preprocessing
├── Customer Shopping Behavior Analysis.pdf   # Detailed analytical report & findings
├── Customer Shopping Behavior Analysis.pptx  # Executive presentation deck
├── Customer behaviour.sql                 # SQL queries for database analysis & segmentation
├── customer beahviour.pbix                # Interactive Power BI Dashboard
├── customer_behaviour.csv                 # Raw dataset
└── README.md                              # Project documentation


🛠️ Tech Stack & Workflow
Python (Customer Behaviour Analysis.ipynb): Data cleaning, missing value imputation, exploratory data analysis (EDA), and feature engineering.

SQL (Customer behaviour.sql): Queries for customer segmentation, purchasing frequency, and revenue distribution.

Power BI (customer beahviour.pbix): Interactive dashboard with key metrics (KPIs), category performance, and demographic breakdowns.

Documentation: Executive summary presentation (.pptx) and in-depth report (.pdf).

📊 Key Highlights & Findings
Total Revenue: ~$233,081 across 3,900 customer transactions.

Average Order Value (AOV): $59.76 with an average review rating of 3.75 / 5.0.

Demographics: Male customers contributed ~67.7% ($157,890) of total sales; Young Adults generated the highest sales among age groups.

Customer Retention: Over 80% of buyers are returning customers, but subscription adoption remains an untapped growth opportunity (~27%).

🚀 Getting Started
View Dashboard: Open customer beahviour.pbix in Power BI Desktop.

Run SQL Script: Execute Customer behaviour.sql in MySQL, PostgreSQL, or your database environment using customer_behaviour.csv.

Explore Data Cleaning: Open Customer Behaviour Analysis.ipynb in Jupyter Notebook or Google Colab.
